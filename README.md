# Mohammad Shahil — Portfolio

A responsive Next.js portfolio starter for Mohammad Shahil.

## Run locally

1. Install Node.js (LTS): https://nodejs.org/
2. Open this folder in VS Code.
3. Open the terminal and run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Deploy free on Vercel

1. Create a GitHub account and a new repository.
2. Upload this project folder to the repository.
3. Sign in at https://vercel.com/ using GitHub.
4. Select **Add New → Project**, import this repository and click **Deploy**.
5. In Project Settings → Domains, choose an available `*.vercel.app` address.

## Before publishing

- Replace the portrait placeholder with your professional photo.
- Add the latest CV as `public/Mohammad-Shahil-CV.pdf` and add a working download link.
- Replace `YOUR_EMAIL_HERE` in `app/page.tsx` with an email address you approve for public display.
- Confirm the joining date and detailed responsibilities at RKQ Contracting.
- Confirm the exact MBA programme title and current study status.
- Review all experience descriptions and remove anything that does not accurately describe your work.

## Notes

This starter intentionally avoids invented achievements, project metrics and unconfirmed contact details.
